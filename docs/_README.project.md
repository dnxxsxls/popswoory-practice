# Timetable

약속시간 조율 + 모임 아카이빙 웹 서비스 (내부 전용).

**언제 만날지 정하고, 만난 걸 남긴다.**
가능시간을 격자에 칠해 모으고(when2meet 방식), 확정된 모임을 사진·후기·정산과 함께 기록으로 축적한다.

## 원칙

1. 하나의 `Event`가 `polling → confirmed → done` 상태만 바꾸며 끝까지 산다 (약속과 기록을 분리하지 않는다).
2. 개인정보를 수집하지 않는다 — 식별은 `표시명 + PIN`뿐.
3. 시간표는 가입할 때 한 번만 등록하고, 이후 모든 약속에 자동 반영된다.
4. 전원 공강 시간대를 자동으로 계산해 후보로 제시한다 — 아무도 응답하기 전에 초안이 나온다.
5. 단, 시간표는 "불가"만 만든다. "가능"은 사람만 만들 수 있다.
